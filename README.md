# Halo CE Enemies for HaloDoom Evolved (HDE version)

Halo: Combat Evolved's enemies (Covenant, Flood, Sentinels and Marines), plus the Digsite / SPV3 / Halo 2 add-on (Drones, Brutes and their Chieftain, Blind Wolf, Thorn Beast, Engineer, Slug Men, Drinol), as UZDoom / GZDoom monsters for **HaloDoom Evolved (Local_DEV)**.

The standalone version, which doesn't need HDE, is in **HaloCE-Enemies-Standalone**.

## Layout

```
packs/<Pack>/        each folder is exactly the root of one pk3: edit files here
  HCE_EnemyAPI_LocalDEV/   enemy AI (overrides HDE's ZScript/BaseAI/enemies_base.zsc)
  HaloCE_Core/             replacement handler, enemy projectiles / explosives, CVars
  HaloCE_Covenant/  HaloCE_Flood/  HaloCE_Sentinels/  HaloCE_Marines/
  HaloCE_Enemies_Digsite/  Digsite / SPV3 / Halo 2 add-on
  HaloCE_Enemies_Voices/   dialogue (optional)
build.py, Build_PK3s.bat   compile packs/ into dist/*.pk3
tools/                     merge_hce_packs.py (used by build.py), update_merged_pack.py
generator/                 the extraction / generation pipeline that made packs/ (see generator/README.md)
docs/PACK_README.md        the full player-facing manual: AI, CVars, replacements, gore, loot ...
```

## Compiling

You need Python 3 and nothing else.

```
python build.py            # every pack -> dist/<Pack>.pk3
python build.py Covenant   # just the packs whose folder name contains "Covenant"
python build.py --bundle   # + dist/HaloCE_HDE_Bundle.pk3 (Core + Covenant + Digsite + API + voices)
python build.py --merged   # + dist/HaloCE_Merged.pk3 (Core + every faction + Digsite)
python build.py --all      # everything
```

On Windows, double-click `Build_PK3s.bat` (it runs `--all`).

The pk3s are byte-stable: the same files always give the same pk3.

**GitHub Actions** (`.github/workflows/build.yml`) compiles everything on every push to `main`. The pk3s are under the run's *Artifacts*. Pushing a tag such as `v1.2` also attaches them to a GitHub Release:

```
git tag v1.2 && git push origin v1.2
```

## Load order

```
HDE (Local_DEV) -> HCE_EnemyAPI_LocalDEV.pk3 -> HaloCE_Core.pk3 -> any faction packs / HaloCE_Enemies_Digsite.pk3
                -> HaloCE_Enemies_Voices.pk3 (optional) -> nashgore.pk3 (optional, last)
```

Or: `HDE -> HaloCE_HDE_Bundle.pk3 -> nashgore.pk3`.

## Editing notes

* **ZScript:** `packs/HaloCE_Core/zscript.txt` includes the core files. Each faction pack has its own `zscript.txt`, and the merge tool combines them.
* **Generated files:** files under `ZScript/HaloCE/hce_<faction>.zsc`, `modeldef.*`, `gldefs.*` and the models were generated by `generator/` from the Halo maps. Small hand edits in `packs/` are fine. A full regeneration overwrites them, so carry the edits into `generator/` too.
* **Defaults:** enemy damage, health and shields are controlled by `hce_nerf_projectiles`, `hce_nerf_health` and `hce_nerf_shields` in `packs/HaloCE_Core/cvarinfo.txt`.
